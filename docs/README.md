# docs 文件索引

這個資料夾存放給後續 Claude agent（以及開發者）閱讀的專案文件，目的是讓 agent 能快速理解這個專案。

## 分類

| 分類 | 文件 | 內容 |
| --- | --- | --- |
| 專案架構 | [architecture.md](./architecture.md) | 專案目的與使用的技術（只記錄技術選型與目的） |

## 維護規則

- 文件分類會**隨需求依序新增**；目前只有「專案架構」，不要預先建立還沒有內容的分類。
- 每新增一個分類（文件），必須同時：
  1. 在上方「分類」表格加上一列並連結到該文件；
  2. 在根目錄的 [`CLAUDE.md`](../CLAUDE.md) 的「需要了解專案時請閱讀」清單加上引用。
- 變更專案使用的技術或目的時，要同步更新對應的文件。
- 文件以繁體中文撰寫。
